# DocQL Go SDK

A Go client for the DocQL document-extraction API (`POST /v1/query-document`).
Module path: `github.com/finoniq/docql-go`.

**Status: pre-release.** `v0.1.0` is not published yet — there is nothing to
install until the first release is announced.
